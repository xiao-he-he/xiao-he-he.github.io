## 图 1 分析：活动展厅式 3D 界面

第一张图是一个活动入口界面，核心不是普通菜单，而是一个可探索的 3D 小场景。画面由强透视空间、弧形巨幕、立体球场模型、墙面海报、浮动任务牌和底部状态栏组成。

主要特征：

- 空间结构像“展厅 + 沙盘”：右侧是弧形白色墙体和蓝色巨幕，中间是凸起的绿色球场平台，左侧是倾斜的活动主视觉墙。
- 信息被放在不同空间层级：大标题在远处墙面，主要交互在中景球场，任务和锁定状态浮在前景，底部是系统状态栏。
- 3D 感来自透视、厚度、投影、平台边缘、墙面弧度和小型棋子道具，而不是单纯的渐变或阴影。
- 蓝紫色背景和白色展厅形成强对比，荧光绿球场作为唯一的场景焦点。
- 活动标题使用超大斜体白字，和英文 `CHAMPIONSHIP`、`POSITIONAL FOOTBALL` 等重复文字带组成品牌氛围。
- UI 元素混合了体育战术图、网格、箭头、十字标记、锁图标、等级徽章、时间倒计时和任务卡。
- 任务状态被视觉化：可进入的模块颜色明亮，未解锁模块变成深灰半透明牌，并叠加锁和说明。
- 顶部返回/主页导航很简洁，是深色长条按钮；底部状态栏则像游戏 HUD，显示结束时间、剩余天数、进度计数。

提取出的色彩倾向：

- 电蓝 / 主视觉蓝：`#1B3BEC`
- 深紫 / 背景压暗：`#3305C8`
- 高亮草绿 / 场景焦点：`#A9D979`
- 展厅白 / 空间主体：`#F5F6F5`
- 冷灰线框：`#D5D7D9`
- 深灰锁定面板：`rgba(20,20,20,.72)`
- 小面积橙色警示：`#FF6A2A`

可迁移到个人网站的设计方法：

- 把个人网站首页设计成一个“作品展厅”或“个人沙盘”，而不是垂直堆卡片。
- 把精选作品、技能、经历、联系入口做成不同的空间模块：中央平台、侧墙海报、悬浮任务牌、底部状态条。
- 让最重要的行动入口使用唯一高亮色，其他模块用灰白或黑色半透明处理。
- 为暂未开放的内容设计“LOCKED / COMING SOON / ARCHIVED”状态，不要只隐藏它们。
- 使用弧形屏幕、倾斜墙面、地面网格、凸起平台、微缩道具来增加空间感。

## 图 2 分析：主页主控台式 UI

第二张图是典型主界面大厅。画面左中是角色和个人信息，右侧是大量悬浮功能菜单，背景是工业建筑空间。整体像一个“个人基地控制台”：信息密集，但主要功能分区明确。

主要特征：

- 主体人物位于左中，作为视觉锚点；右侧功能面板以透视角度漂浮排列，形成明显的前后层级。
- 背景不是纯色，而是工业场景，包含桥架、栏杆、机械结构、建筑层次，提供世界观和深度。
- 功能菜单是黑色半透明矩形，大量使用斜切边、透视、亮色顶边、几何图标和中英混排。
- 资源栏位于顶部，包含时间、数值、加号按钮、货币图标，像 HUD 状态系统。
- 左侧有等级圆环、姓名、ID 和对话框，像个人档案卡。
- 右侧功能区不是等宽网格，而是错落的面板群：大面板、小面板、横条面板、状态入口混合排列。
- 面板内部常见图形有圆环、三角阵列、点阵、横向状态线、色条、十字准星、菱形标记。
- 视觉重心由黑、灰、白构成，荧光黄绿做系统高亮，红色和黄色只用于提醒、资源或活动入口。

提取出的色彩倾向：

- 近黑 UI：`#121314`
- 黑灰浮层：`#212526`
- 工业深灰：`#39393B`
- 冷灰绿背景：`#4D5551`
- 奶油白文字：`#E5E3D7`
- 警示黄绿：`#A7D129`
- 暗橄榄绿：`#89947A`
- 红色强调：`#C7353D`

可迁移到个人网站的设计方法：

- 将个人头像、照片或抽象 3D 形象作为左侧视觉锚点。
- 将作品、技能、日志、联系等栏目变成右侧悬浮控制台入口。
- 让导航不只是顶部菜单，而是整个屏幕中的一组可点击系统模块。
- 用顶部 HUD 展示当前身份状态：`AVAILABLE`、`UPDATED 2026.06`、`PROJECTS 04`、`FOCUS WEB/AI/VISUAL`。
- 使用黑色半透明面板承载高密度信息，但每个面板必须有明确功能。
- 通过大小、位置、颜色和透视角度区分主入口与次入口。

## 补充设计原则

### 1. 页面可以像一个可操作空间

第一份文档强调平面设计和信息图层；本补充建议进一步把首页做成一个“可操作空间”：

- 桌面端首屏可以是 3D 展厅、基地控制台、作品沙盘或漂浮面板大厅。
- 背景负责世界感，中景负责主体身份，前景负责导航和操作。
- 作品不一定以卡片列表展示，可以成为墙面海报、沙盘节点、悬浮任务牌或控制台入口。
- 用户一进来就能点击入口，不需要先读长篇介绍。

### 2. 使用明确的前中后景

建议把页面分为三个景深层：

- 背景层：工业空间、抽象展厅、网格地面、弧形屏幕、雾化背景图。
- 中景层：个人头像、3D 物体、作品平台、主标题、当前身份状态。
- 前景层：导航按钮、任务卡、状态栏、CTA、联系入口。

不要把所有元素都压在同一个平面上。通过 `z-index`、透明度、阴影、模糊、透视和遮挡关系建立层级。

### 3. 模块应有状态

每个入口都应该像一个系统模块，而不是普通链接：

- `ACTIVE`：当前可点击，使用高亮色和清晰边框。
- `LOCKED`：暂未开放，使用深灰半透明和锁图标。
- `ARCHIVED`：历史项目，降低亮度但可查看。
- `NEW`：近期更新，使用小色块或角标。
- `IN PROGRESS`：进行中，使用扫描线或进度条。

个人网站可以把这些状态映射为：

- 精选作品：`ACTIVE`
- 未来文章：`LOCKED`
- 老项目：`ARCHIVED`
- 新作品：`NEW`
- 正在做的研究：`IN PROGRESS`

### 4. 入口布局要有“主次面板”

不要把所有入口做成同等大小。参考第二张图，功能面板应分为：

- 主面板：最大，承载当前重点，例如 `SELECTED WORKS`。
- 次面板：中等，承载 `PROFILE`、`SKILLS`、`LOG`。
- 小面板：承载社交链接、状态、徽章、计数器。
- 底部条：承载更新时间、可用状态、当前项目数量。

这样用户能立刻知道先看哪里。

### 5. 个人网站不应照搬游戏 HUD

借鉴界面方法，但内容必须替换为个人信息：

- 等级圆环可以变成经验年限、项目数量或专注领域指数。
- 资源栏可以变成作品数、文章数、可合作状态、更新时间。
- 任务入口可以变成作品集、简历、研究日志、联系方式。
- 活动倒计时可以变成作品更新周期、项目上线日期或可预约时间。
- 角色对话框可以变成一句个人介绍或当前工作状态。

## 可追加到第一份文档的 Agent 提示词

请在第一份《明日方舟风格个人网站 Agent 提示词》的基础上，进一步采用“空间化 UI / 主控台 / 展厅沙盘”的网页结构。不要把页面做成普通长列表作品集，而要让首屏像一个可操作的个人控制台。

### 首屏空间结构

请把首屏拆成三层：

1. 背景层：工业感或抽象展厅空间，可以是浅色 3D 房间、深色基地背景、地面网格、弧形屏幕、斜向墙面或远景结构。
2. 中景层：个人身份核心，可以是姓名大字、个人头像、抽象 3D 模型、作品沙盘或主视觉平台。
3. 前景层：可点击 UI 模块，包括作品入口、技能入口、日志入口、联系入口、状态栏和主 CTA。

页面必须有明确的空间透视。至少使用以下一种方式：

- CSS `perspective` 和 `transform: rotateX/rotateY/skew` 制作倾斜面板。
- Three.js 制作简单 3D 平台、展厅、晶体或漂浮屏幕。
- 纯 CSS 构建等距视角地面、凸起平台、弧形屏幕和浮动卡片。
- 使用真实背景图或生成式背景图，再叠加半透明 HUD 面板。

### 主控台布局

请设计一个类似个人基地的主控台：

- 左侧或中心放个人头像 / 姓名 / 身份等级圆环。
- 右侧放 4-6 个悬浮功能面板：`WORKS`、`PROFILE`、`SKILLS`、`LOG`、`CONTACT`、`NOW`。
- 顶部放 HUD 状态栏：`AVAILABLE`、`UPDATED 2026.06`、`PROJECTS 04`、`LOCATION`。
- 底部放系统提示条：当前焦点、最近更新、合作状态或邮箱。
- 主要入口使用更大面板和高亮边线，次要入口使用更小面板。

面板不要严格排成普通网格。请用错位、前后层级、轻微透视和不同尺寸制造动态关系，但不要让文字互相遮挡。

### 展厅沙盘布局

如果选择浅色展厅方向，请参考活动界面的空间方法：

- 使用白色或浅灰 3D 展厅作为背景。
- 墙面上放巨型标题和作品海报。
- 中央放一个凸起平台，平台上展示“作品地图”或“技能坐标”。
- 右侧放一个大屏幕展示当前精选项目。
- 前景放任务牌式入口，例如 `CASE 01 / WEB`、`CASE 02 / VISUAL`。
- 未完成内容显示为深灰锁定牌，不要简单隐藏。

### 色彩方向

可以根据页面气质选择两种模式：

模式 A：活动展厅高亮模式

```css
--space-blue: #1B3BEC;
--deep-violet: #3305C8;
--field-lime: #A9D979;
--gallery-white: #F5F6F5;
--cool-gray: #D5D7D9;
--locked-panel: rgba(20, 20, 20, 0.72);
--signal-orange: #FF6A2A;
```

适合更明亮、年轻、活动感强的个人网站。高亮绿只用于主平台、关键按钮和当前选中项。

模式 B：主控台工业模式

```css
--hud-black: #121314;
--panel-black: #212526;
--industrial-gray: #39393B;
--fog-gray: #4D5551;
--text-cream: #E5E3D7;
--signal-lime: #A7D129;
--warning-red: #C7353D;
--status-yellow: #F0D34A;
```

适合更成熟、冷静、作品控制台式的个人网站。黑色面板要半透明，并保留背景空间深度。

### UI 组件规则

请实现以下组件：

- 顶部 HUD：小图标、状态文字、计数器、更新时间。
- 等级/身份圆环：展示年限、作品数、身份代号或专注领域。
- 悬浮功能面板：黑色或白色半透明，带图形标识、英文标题、中文副标题。
- 任务牌：包含编号、状态、简短说明和 CTA。
- 锁定牌：深灰、低透明、高对比锁图标、提示开放条件或计划。
- 底部状态栏：显示当前页面状态、最近更新、项目进度。
- 小型标签条：重复关键词、分类、坐标或项目类型。

图形语言使用：

- 三角阵列
- 圆环仪表
- 菱形光标
- 点阵
- 横向扫描线
- 斜切矩形
- 细线网格
- 小色块状态灯
- 轻微故障色条

### 动效补充

动效要像“主控台启动”和“空间面板响应”：

- 页面加载时，背景先出现，随后主体、HUD、面板依次滑入。
- 面板 Hover 时轻微向前浮起，边线发亮，背景图层有很小的视差。
- 主面板 Hover 时可以展开二级信息，但不要遮挡其他主要入口。
- 锁定面板 Hover 时只显示提示，不要做夸张摇晃。
- 顶部状态数字可以轻微跳变或滚动出现。
- 滚动页面时可模拟相机推进：首屏控制台退后，作品详情进入前景。

提供 `prefers-reduced-motion` 支持，减少视差、漂浮和扫描动画。

### 验收标准补充

完成后请检查：

- 首屏是否像一个可操作的空间，而不是普通卡片列表。
- 用户是否能立刻识别主入口、次入口和状态信息。
- 3D 空间、HUD、浮动面板是否服务于个人网站内容，而不是只有装饰。
- 面板是否有明确状态：可用、锁定、归档、进行中、最新。
- 高亮色是否集中在主行动和当前选中项，避免全屏乱亮。
- 透视和遮挡是否没有影响文字可读性。
- 移动端是否简化为空间感较弱但结构清晰的单列控制台。
- 是否没有复制《明日方舟》的角色、Logo、图标、原始 UI 文案或专有术语。
