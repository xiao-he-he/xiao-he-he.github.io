# 明日方舟平面设计风格个人网站 Agent 提示词

资料来源：
- https://www.ignoredone.space/index.php/arknightsdesign/
- https://www.ignoredone.space/index.php/graphic-design-arknights/

本文件用于指导 Agent 借鉴《明日方舟》相关视觉资源的平面设计语言，设计一个原创个人网站。目标是学习其信息组织、图形 UI、层级、空间感与科技感，不复制游戏素材、Logo、角色、专有图标或可识别版权元素。

## 视觉特色总结

《明日方舟》式平面设计的核心不是单纯“黑白灰科技风”，而是“高密度信息图层 + 工业/战术 UI + 编辑设计感 + 克制的高亮色”。页面通常有大量留白或低对比背景，但通过粗标题、细线框、编号、坐标、角标、重复几何形、扫描线、噪点和半透明面板形成复杂层次。

主要特征：

- 版式使用强网格，但常用错位、裁切、越界和非对称构图制造张力。
- 标题很大，常用粗体无衬线英文或压缩字形；正文和标注则极小，像技术说明、档案标签、仪表读数。
- 信息元素被拆成模块：编号、日期、身份、状态、分类、短标签、坐标、进度、警示符号，而不是长段说明。
- 背景常有浅灰网格、虚线、细框、十字准星、坐标线、圆环、矩形切片、重复三角形或方块阵列。
- 色彩以白、灰、黑为骨架，局部加入一个强强调色，例如荧光绿、橙、黄、红、冰蓝。强调色面积不大，但位置强势。
- 图形 UI 偏“设备界面”和“资料档案”：窗口、标签、状态条、折角卡片、边框、切角矩形、圆形仪表、条形码、像素块、警示线。
- 立体感不靠厚重拟物，而靠多层半透明玻璃、前后错位、投影、模糊、斜向透视、3D 物体/角色与 2D UI 的穿插遮挡。
- 图片通常不会被规整地放进圆角卡片，而是与文字、线框和图形共同构成一张“视觉海报”。
- 动效适合使用轻微扫描、数字跳变、悬浮位移、视差、面板展开、线条绘制和图层淡入，不适合弹性卡通动效。

## 可直接给 Agent 的提示词

你是一名高级网页视觉设计与前端实现 Agent。请为我设计并实现一个原创个人网站，视觉方向参考《明日方舟》相关平面设计语言：高密度信息图层、工业/战术 UI、编辑化海报排版、黑白灰基础、单一高亮色、细线框、编号系统、坐标与状态标签、半透明多层界面，以及 2D UI 与 3D 空间感结合。不要复制《明日方舟》的 Logo、角色、UI 图标、专有术语、游戏素材或任何可识别版权内容，只借鉴设计方法。

网站主题：个人作品集 / 个人主页。第一屏必须直接是可用的个人主页体验，不要做营销式落地页。页面需要展示身份、作品、技能、项目、联系方式，并让整体像一套精密的个人档案系统。

### 整体风格

使用白、近黑、冷灰作为主色，选择一个高亮色作为系统色，例如荧光绿 `#53ff18`、工程橙 `#ff6a00`、警示黄 `#d9ff00` 或冰蓝 `#9cc7ff`。高亮色只用于关键编号、状态、按钮激活态、线条、图形标记和少量背景几何，不要大面积铺满。

整体视觉应呈现：

- 冷静、精密、工程化、信息密集。
- 有明显网格系统，但允许元素错位、压边、跨栏、裁切。
- 页面像一张可交互的信息海报，而不是普通卡片式作品集。
- 多用直角、切角、细边框、线性图标、极小标签、编号和状态文字。
- 避免大圆角、柔和渐变泡泡、可爱插画、厚重阴影、常规 SaaS 卡片堆叠。

### 页面结构

设计以下区域：

1. 顶部固定导航：左侧为个人代号或姓名缩写，右侧为 WORK / PROFILE / LOG / CONTACT。导航应像设备状态栏，带小编号、细分隔线和当前状态。
2. Hero 档案区：左侧或中心放超大姓名/代号标题，标题可被图片、线框或几何图层部分遮挡。周围放身份标签、当前状态、坐标、更新时间、短句座右铭。
3. 个人信息面板：用档案字段展示 Role、Location、Focus、Tools、Availability。每个字段像系统参数，而不是普通自我介绍。
4. 作品区：使用非对称网格展示项目。每个项目用编号、类型、年份、技术栈、短描述、状态条和缩略图。项目卡片可以是切角矩形、透明面板或分层海报块。
5. 技能区：不要普通进度条。改用雷达图、坐标矩阵、模块阵列、标签群或类似仪表 UI 的布局。
6. 时间线/日志区：用细竖线或横向坐标轴展示经历，每条记录包含编号、日期、标题、状态、简短说明。
7. 联系区：像终端提交面板或任务派发界面，包含邮箱、社交链接和一个醒目的主行动按钮。

### 信息元素编排

请大量使用“真实有用的小信息块”，但不要堆无意义装饰。每个装饰元素最好伪装成系统信息：

- 编号：`ID-001`、`CASE 04`、`NODE 12`、`LAYER 03`
- 状态：`ONLINE`、`READY`、`ARCHIVED`、`IN PROGRESS`
- 坐标：`X: 031 / Y: 204`、`N 31.2304 / E 121.4737`
- 时间：`UPDATED 2026.06`
- 类型：`WEB`、`VISUAL`、`SYSTEM`、`RESEARCH`
- 参数：`FOCUS 82%`、`SIGNAL ACTIVE`、`PUBLIC PROFILE`

文字层级：

- H1 使用超大、粗重、紧凑的无衬线，允许跨越 2-3 栏。
- H2 使用短英文或中英混排，例如 `SELECTED WORKS / 作品档案`。
- 正文保持简短，像资料卡摘要。
- 辅助标签使用 10-12px 小字、全大写英文、宽松字距。
- 中文不要大段堆叠，每段 1-2 行。

### 图形 UI 语言

请在 CSS/HTML 中实现以下图形元素：

- 细线网格背景，透明度很低。
- 角标线、L 形边框、十字准星、坐标刻度。
- 重复小三角形、小方块、点阵或斜线阵列。
- 半透明玻璃面板，使用 `backdrop-filter: blur(...)`，但保持边框锐利。
- 切角矩形，可用 `clip-path: polygon(...)`。
- 条形码/扫描线，可用 repeating-linear-gradient。
- 分层圆环、仪表盘、雷达扫描扇形。
- 斜向高亮线穿过页面，制造速度和切割感。

按钮不要做普通圆角胶囊。主按钮可以像系统命令键：直角或小切角、细边框、左侧编号、右侧箭头或状态灯。悬浮时使用高亮色填充、线条偏移、轻微扫描光。

### 立体与 3D 感

如果实现 3D 或伪 3D，请遵循：

- 第一屏可以放一个抽象 3D 物体，例如低多边形晶体、线框立方体、漂浮终端模块、旋转数据核心或个人头像的分层剪影。
- 3D 物体不要放在卡片里，应与背景 UI 图层穿插，形成前景/中景/背景。
- 使用轻微透视、视差和遮挡：文字可在 3D 物体后方被部分遮住，线框可在物体前方经过。
- 阴影应克制，更多依靠透明度、模糊、景深和叠层制造空间。
- 若不用真实 3D，可用 CSS `transform: perspective(...) rotateX(...) rotateY(...)` 给面板做轻微倾斜，并配合多层线框。

### 动效

动效要像系统界面启动：

- 页面加载时，网格、线框、标题、状态标签分层淡入。
- 标题可以有短暂扫描/遮罩揭示效果。
- 项目卡片悬浮时，边框高亮、坐标线延伸、缩略图轻微放大。
- 背景几何元素缓慢漂移，幅度很小。
- 避免夸张弹跳、卡通摆动和过度炫光。
- 提供 `prefers-reduced-motion` 支持。

### 响应式规则

桌面端使用 12 栏或 8 栏网格，允许复杂错位。移动端要收敛为清晰的单列档案流，但保留编号、状态栏、切角面板和少量几何图形。所有文字必须不重叠、不溢出按钮或卡片。超大标题在移动端允许换行或裁切，但不能挡住核心操作。

### 内容要求

请生成完整可运行的网站，不要只给概念图。内容可以使用占位个人信息，但要真实像作品集：

- 姓名/代号
- 一句话身份描述
- 4 个精选项目
- 6-10 个技能或工具
- 4 条经历/日志
- 联系方式

所有图片如果使用占位图，应选择抽象几何、界面截图、作品缩略图或生成式图形，不要使用《明日方舟》角色或素材。

### 验收标准

完成后请检查：

- 第一屏是否一眼能看出个人身份和主行动。
- 是否有《明日方舟》式的信息密度、工程 UI 和海报排版，而不是普通模板网站。
- 高亮色是否克制，是否形成清晰焦点。
- 小标签、编号、线框、几何元素是否服务于信息层级。
- 桌面和移动端是否没有文字重叠。
- 是否没有复制游戏专有素材、Logo、角色或图标。
