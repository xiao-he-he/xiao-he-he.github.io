## 当前网站观察

当前网站内容结构已经完整，包含：

- 顶部导航：关于、文章、触星、追番、联系。
- Hero：头像、姓名“萧和和”、身份说明、个人简介、标签。
- 文章作品：三篇设计/开发相关内容。
- 触星：独立游戏项目介绍和 3D、10+、RPG、1人等数据。
- 追番：Bangumi 数据网格。
- 联系方式：邮箱、GitHub、Bilibili。
- 固定音乐播放器。

当前视觉优点：

- 版面干净，留白充足。
- 中文排版稳定，阅读性较好。
- 已经有柔和色调和轻微噪点质感。

当前主要问题：

- 整体更像淡雅纸质博客，还没有明显的《明日方舟》式信息密度和工业 UI。
- 背景偏米白，和参考图中的天空蓝、虹彩云层、蓝紫阴影联系不够强。
- Hero 首屏过于静态，头像和文字像普通个人简介，没有“主控台 / 档案系统 / 空间入口”的第一印象。
- 文章、触星、联系等模块仍是普通白色卡片，缺少状态、编号、坐标、HUD、锁定态、任务面板等系统感。
- 《触星》项目很适合作为主视觉核心，但现在只是普通介绍卡，没有被做成“任务平台 / 项目沙盘 / 主线模块”。
- 音乐播放器目前像普通小组件，可以改造成底部 HUD 状态栏的一部分。

## 改进目标

请基于现有 `index.html` 改造网站，不要重写成完全无关的新站。保留现有内容、栏目、链接、Bangumi 加载逻辑和音乐播放器功能，但重塑视觉系统。

目标方向：

- 从“淡雅个人博客”升级为“明亮虹彩色调 + 明日方舟式空间化个人主控台”。
- 第一屏要像一个可操作的个人档案界面，而不是普通头像介绍。
- 保留参考图 `色调.jpg` 的柔和天空、云层、虹彩、奶油黄光源。
- 融入《明日方舟》式信息图层、HUD、编号、状态、模块面板、错位布局、3D/伪 3D 空间感。
- 不复制《明日方舟》的角色、Logo、原始图标、专有术语和 UI 文案，只借鉴设计方法。

## 色彩改造

当前米白背景过于单一，请改为“云层虹彩 + 冷静蓝紫 UI”的体系。

推荐 CSS 变量：

```css
:root {
  --sky: #86B6D8;
  --sky-light: #90BADD;
  --mist: #EEF3FA;
  --pearl: #F7F8FB;
  --cloud-line: #B6BCD1;
  --shadow-blue: #6D7BAD;
  --violet-blue: #7082B7;
  --soft-violet: #8A96CC;
  --lavender-pink: #BFA0C2;
  --peach: #E7C0C1;
  --sun-cream: #FAEBB1;
  --aqua-glint: #9EEAD8;
  --ink: #39425F;

  --hud-black: rgba(18, 19, 20, 0.78);
  --panel-white: rgba(247, 248, 251, 0.62);
  --panel-line: rgba(182, 188, 209, 0.56);
  --signal-lime: #A9D979;
  --signal-blue: #1B3BEC;
}
```

使用比例：

- 55% 天空蓝、珍珠白、雾白背景。
- 20% 蓝紫阴影和深蓝文字。
- 15% 半透明面板与细线网格。
- 7% 奶油黄光源。
- 3% 青绿、蜜桃粉、荧光绿点缀。

背景建议：

- 全站背景使用 `色调.jpg` 的色彩精神，但不要简单铺图。
- 用多层 `radial-gradient` 模拟云层柔光：蓝天、奶油黄中心、蜜桃粉、淡青折射、蓝紫暗部。
- 叠加 3%-6% 的噪点，保留现有细腻质感。
- 在 Hero 和触星区域允许更强光源，其他区域保持可读。

## 首屏改造

当前 Hero 是头像 + 文本。请改成“个人档案主控台”：

布局建议：

- 左侧或中心保留头像，但头像不要只是方形照片卡。把它变成“档案身份核心”：头像 + LV/ID/STATUS 圆环 + 当前身份标签。
- 右侧或后方放超大姓名“萧和和”，可被线框、坐标、半透明面板部分遮挡。
- 增加顶部 HUD 信息：`STATUS / AVAILABLE`、`UPDATED 2026.06`、`FOCUS / LEVEL DESIGN`、`PROJECT / TOUCH THE STARS`。
- 增加 4-5 个首屏入口面板：`WORKS`、`TOUCH THE STARS`、`BANGUMI LOG`、`CONTACT`、`NOW PLAYING`。
- 入口面板带编号、状态、短说明和箭头，不要只是普通导航链接。

Hero 应具备明确空间层级：

- 背景层：云层虹彩渐变、细网格、弧形线框、坐标刻度。
- 中景层：头像档案、姓名、个人简介。
- 前景层：可点击模块、状态条、音乐 HUD。

请避免第一屏继续保持大面积空白但缺少信息。留白可以保留，但必须被网格、HUD、坐标、状态标签和浅色图形组织起来。

## 导航改造

当前导航很干净，但普通。请改为“系统状态栏”：

- 左侧：`XIAO HEHE / PROFILE NODE`
- 中部或右侧：栏目链接，保留中文，但增加小编号，例如 `00 关于`、`01 文章`、`02 触星`。
- 右侧可增加 `ONLINE` 状态灯或 `UPDATED 2026.06`。
- 当前栏目高亮不要只用下划线，可以用细线框、底部扫描线、状态点或小色块。
- 导航背景使用半透明雾白或极深 HUD 黑，视整体模式决定。

## 文章区改造

当前文章卡片是大白卡片，气质偏纸质。请改成“设计档案 / 任务记录”：

- 每篇文章为一个 `CASE` 模块，例如 `CASE 01 / LEVEL DESIGN`。
- 保留标题、描述、阅读全文链接。
- 增加状态字段：`TYPE`、`FIELD`、`METHOD`、`STATUS: PUBLIC`。
- 卡片边框使用细线和切角，不使用大圆角。
- 卡片内加入低透明编号、坐标线、点阵、横向扫描线。
- 第三篇可以作为横跨全宽的主记录，但要有更强的视觉层级，而不是简单变宽。

Hover：

- 边框亮起为淡青或奶油黄。
- 编号或状态条轻微移动。
- 背景出现很淡的蓝紫网格。

## 触星区改造

《触星》是网站最适合做视觉核心的部分。请把它从普通统计卡改成“主线项目沙盘 / 独立游戏任务面板”。

建议：

- 使用更大的空间化面板，占据页面视觉中心。
- 左侧保留项目介绍，右侧的 3D、10+、RPG、1人改造成四个悬浮数据模块。
- 增加一个“项目平台”视觉：可以用 CSS 伪 3D 地面网格、浮动晶体、星图、坐标点、轨道线或简单 Three.js 抽象模型。
- 主色使用奶油黄和淡青作为“触星”的光源，蓝紫作为阴影。
- 标题可以写成 `TOUCH THE STARS / MAIN PROJECT`，中文“触星”作为强主标题。
- 加入状态：`STATUS: IN DEVELOPMENT`、`MODE: SOLO`、`GENRE: 3D RPG`、`CYCLE: 10+ YEARS`。
- 入群邮箱作为主 CTA，按钮做成系统命令键：`REQUEST ACCESS / 加入触星计划`。

不要让触星区只像表格。它应该像一个可进入的项目入口。

## 追番区改造

追番记录可以被设计成“媒体档案库 / WATCH LOG”：

- Tabs 改成分段控制器，带编号和状态：`DOING`、`COLLECTED`、`WISH`。
- 番剧卡片保留封面，但外层加上档案字段：进度、评分、状态。
- 卡片可以是竖向情报卡，使用蓝紫细边框和淡青状态点。
- 网格保持清晰，不要过度透视，以免封面难看。
- 加载失败和空状态也要设计成系统提示面板。

## 联系区改造

当前联系区较平。请改为“通信终端 / CONTACT TERMINAL”：

- 三个联系方式变成终端模块：`MAIL NODE`、`GITHUB REPO`、`BILIBILI CHANNEL`。
- 每个模块带小图标、状态灯、短说明、复制/打开动作。
- 邮箱作为主行动入口，视觉层级最高。
- 背景可放淡淡的通信线、节点图、扫描线。

## 音乐播放器改造

当前音乐播放器位置合理，但视觉和主控台不统一。请改造成底部 HUD 模块：

- 保留播放、上一首、下一首、音量、随机功能。
- 样式从普通白条改为半透明 HUD 面板。
- 显示 `NOW PLAYING`、曲名、艺术家。
- 加入小型频谱条或扫描线动效。
- 如果音频格式不支持，错误提示要清楚，不要显示乱码。
- 移动端应收缩成底部迷你播放器，避免遮挡内容。

## 字体方向

当前中文标题使用宋体感很强，优点是有个人气质，但和明日方舟式 UI 的工业感不够统一。建议：

- Hero 大标题可保留强中文标题，但需要搭配粗重无衬线英文系统文字。
- UI 标签、编号、状态全部使用等宽字体。
- 正文仍使用清晰中文无衬线，保证阅读。
- 不要让所有标题都文艺化。文章标题可以保留中文气质，UI 元素必须工程化。

## 动效要求

请加入克制的系统动效：

- 页面加载时：背景光层、头像档案、姓名、HUD、入口面板依次出现。
- 面板 Hover：轻微前移、边框高亮、扫描线掠过。
- 导航切换：状态点移动或下划线扫描。
- 触星区：星图/轨道线缓慢漂移。
- 音乐播放器：播放时频谱条轻微跳动。

必须支持 `prefers-reduced-motion`，关闭大部分位移和循环动画。
