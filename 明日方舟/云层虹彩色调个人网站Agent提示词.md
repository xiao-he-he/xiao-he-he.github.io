# 云层虹彩色调个人网站 Agent 提示词

参考图片：`E:\下载\个人网站\色调.jpg`

本文件用于指导 Agent 从参考图中提取色调语言，并应用到个人网站设计。目标是借鉴“云层、天光、虹彩折射、柔和发光”的色彩构成，而不是照搬图片内容。

## 色调构成分析

这张图的整体色调是高明度、低到中等饱和度、低对比的梦幻天空色。它不是强烈霓虹，而是“被云层散射后的柔光虹彩”：蓝色负责空气感和空间感，蓝紫负责阴影体积，奶油黄负责光源，桃粉和薰衣草紫负责过渡，少量青绿制造虹彩折射。

提取出的代表色：

| 用途 | 色值 | 说明 |
|---|---:|---|
| 主背景天蓝 | `#86B6D8` | 最大面积的晴空蓝，适合作为页面背景或大面积渐变底色 |
| 浅天空蓝 | `#90BADD` | 比主背景更轻，适合面板、柔光、Hover 背景 |
| 蓝紫阴影 | `#6D7BAD` | 云层暗部，适合作为正文文字、阴影、深色 UI 层 |
| 雾感蓝紫 | `#7082B7` | 用于二级背景、边框、渐变暗端 |
| 珍珠灰蓝 | `#B6BCD1` | 低对比分隔线、玻璃面板、辅助文字 |
| 奶油日光黄 | `#FAEBB1` | 主光源色，适合 CTA、重点数字、发光中心 |
| 蜜桃粉 | `#E7C0C1` | 温柔强调色，适合标签、装饰光晕、头像边缘光 |
| 柔紫蓝 | `#8A96CC` | 用于按钮阴影、卡片浮层、二级强调 |
| 薰衣草粉紫 | `#BFA0C2` | 用于渐变过渡、装饰图形、轻柔边框 |
| 淡青折射 | `#9EEAD8` | 图中局部青绿色，可作为稀有高光点缀 |

建议比例：

- 55% 天蓝/浅蓝背景：`#86B6D8`、`#90BADD`
- 20% 蓝紫/雾紫阴影：`#6D7BAD`、`#7082B7`、`#8A96CC`
- 15% 珍珠白/雾白面板：`#F7F8FB`、`#EEF3FA`、`#B6BCD1`
- 7% 暖光：`#FAEBB1`、`#FFE6A8`
- 3% 虹彩点缀：`#E7C0C1`、`#BFA0C2`、`#9EEAD8`

视觉关键词：

- 高明度
- 柔和
- 空气感
- 低对比
- 半透明
- 云雾渐变
- 逆光边缘
- 虹彩折射
- 奶油色发光
- 蓝紫阴影

## 可直接给 Agent 的提示词

你是一名高级网页视觉设计与前端实现 Agent。请为我设计一个原创个人网站，色调参考一张“虹彩云层日光”图片：晴空蓝背景、蓝紫云影、奶油黄色光源、蜜桃粉过渡、薰衣草紫阴影、少量青绿色虹彩折射。整体应明亮、柔和、梦幻、有空气感，但不能幼稚、糖果化或过度霓虹。

网站用途：个人主页 / 个人作品集。页面需要展示姓名、身份、作品、技能、经历和联系方式。请让色彩成为网站气质的核心：像云层中的光从页面内部透出，界面层次轻盈、半透明、干净。

### 色彩方向

请使用以下色板作为基础：

```css
:root {
  --sky: #86B6D8;
  --sky-light: #90BADD;
  --mist: #EEF3FA;
  --pearl: #F7F8FB;
  --cloud-line: #B6BCD1;
  --shadow-blue: #6D7BAD;
  --violet-blue: #7082B7;
  --soft-violet: #8A96CC;
  --lavender-pink: #BFA0C2;
  --peach: #E7C0C1;
  --sun-cream: #FAEBB1;
  --sun-glow: #FFE6A8;
  --aqua-glint: #9EEAD8;
  --ink: #39425F;
}
```

背景不要使用纯白或纯黑。主背景应是天空蓝到珍珠白的柔和渐变，可以叠加大面积模糊光斑：

- 顶部：浅天空蓝
- 中部：珍珠白、淡粉、淡青的云雾过渡
- 视觉焦点：奶油黄柔光
- 底部或侧边：蓝紫阴影压住画面

### 色彩使用规则

- 页面 70% 以上保持浅色和低对比，让画面有空气感。
- 深色文字不要用纯黑，使用 `#39425F` 或 `#4B5575`。
- CTA 主按钮使用奶油黄到蜜桃粉渐变，但文字要用深蓝紫保证可读性。
- 次级按钮使用半透明浅蓝或珍珠白，边框用低透明蓝紫。
- 链接、选中态和细节高光可以使用淡青色 `#9EEAD8`，但面积要小。
- 阴影不要用黑色重阴影，使用蓝紫色透明阴影，例如 `rgba(109, 123, 173, 0.22)`。
- 面板要像云层前方的玻璃片：半透明、轻模糊、低对比边框。
- 避免纯高饱和粉、纯紫、纯青大面积出现，否则会变成廉价霓虹。

### 页面结构与色调应用

1. Hero 首屏：
   - 背景使用天空蓝渐变。
   - 在姓名或头像背后放一个奶油黄柔光中心。
   - 标题使用深蓝紫文字，可带轻微白色内光或浅色描边。
   - 周围点缀半透明云雾形状、柔光圆斑、低透明虹彩渐变。

2. 个人简介区：
   - 使用珍珠白半透明面板。
   - 面板边缘有淡蓝紫边框。
   - 重点标签用蜜桃粉和淡青色做小面积标记。

3. 作品区：
   - 每个作品卡片像漂浮在云层中的玻璃板。
   - 缩略图可使用柔和渐变遮罩，Hover 时出现暖黄色边缘光。
   - 项目编号使用蓝紫，项目状态使用淡青或奶油黄。

4. 技能区：
   - 用淡蓝、薰衣草紫、蜜桃粉的小标签或胶囊展示技能。
   - 标签背景透明度低，边框轻，避免一整片彩色块。

5. 时间线区：
   - 时间线主线使用珍珠灰蓝。
   - 关键节点用奶油黄小光点。
   - Hover 时节点扩散出淡粉或淡青光晕。

6. 联系区：
   - 让它像日光最亮的位置，但不要刺眼。
   - 主行动按钮用 `#FAEBB1` 到 `#E7C0C1` 的柔和渐变。
   - 背景可以有轻微的云层形态或模糊渐变。

### 渐变建议

可以使用这些渐变方向：

```css
background:
  radial-gradient(circle at 58% 42%, rgba(250,235,177,.75), transparent 28%),
  radial-gradient(circle at 38% 45%, rgba(158,234,216,.42), transparent 24%),
  radial-gradient(circle at 44% 35%, rgba(231,192,193,.5), transparent 30%),
  linear-gradient(180deg, #86B6D8 0%, #EEF3FA 48%, #7082B7 100%);
```

面板可以使用：

```css
background: rgba(247, 248, 251, 0.58);
border: 1px solid rgba(182, 188, 209, 0.48);
box-shadow: 0 24px 80px rgba(109, 123, 173, 0.22);
backdrop-filter: blur(18px);
```

按钮可以使用：

```css
background: linear-gradient(135deg, #FAEBB1 0%, #E7C0C1 55%, #9EEAD8 100%);
color: #39425F;
box-shadow: 0 14px 36px rgba(250, 235, 177, 0.38);
```

### 质感与图形

请营造“云层柔光”的质感，但不要直接把云图片当背景铺满。可以用 CSS 和图形层模拟：

- 大尺寸 `radial-gradient` 光斑。
- 低透明模糊椭圆，模拟云雾。
- 柔和噪点纹理，透明度控制在 3%-6%。
- 半透明玻璃面板。
- 细腻的蓝紫投影。
- 暖黄色边缘光。
- 少量青绿色折射高光。

如果使用 3D 或拟 3D 元素，建议选择玻璃球、云状抽象体、漂浮的半透明面板、柔光晶体或分层头像卡。材质应是磨砂玻璃、珍珠、柔光塑料或半透明云母，而不是金属、赛博霓虹或暗黑科技。

### 字体与可读性

- 标题可以使用圆润但克制的无衬线字体，字重 600-800。
- 正文使用深蓝紫，不要使用浅灰小字导致不可读。
- 在浅黄色、浅粉色背景上，文字必须使用 `#39425F` 之类深蓝紫。
- 小标签可以使用全大写英文，但透明度不要低于 70%。
- 所有文字与背景对比必须足够，尤其是按钮、导航和项目说明。

### 禁止事项

- 不要使用纯黑背景。
- 不要使用高饱和赛博霓虹紫/粉/蓝大面积渐变。
- 不要做成儿童糖果风、二次元粉色模板或普通蓝白企业站。
- 不要用沉重黑色阴影。
- 不要把所有卡片都做成强圆角玻璃拟态，圆角应克制。
- 不要让浅色文字压在浅黄色或浅蓝色背景上。

### 验收标准

完成后请检查：

- 第一眼是否像“晴空、云层、柔光、虹彩折射”的色调。
- 页面是否明亮柔和，但仍然有清晰的信息层级。
- 奶油黄是否只用于光源和重点行动，而不是到处铺满。
- 蓝紫阴影是否帮助建立体积和可读性。
- 桃粉、薰衣草紫、淡青是否只是点缀和过渡。
- 桌面和移动端是否都保持舒展、干净、不刺眼。
- 所有正文、按钮和导航是否有足够对比度。
